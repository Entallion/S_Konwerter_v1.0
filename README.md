# 📊 S_Konwerter (GUI)

**K_Konwerter** to aplikacja z graficznym interfejsem (GUI) umożliwiająca automatyczne generowanie raportów pomiarowych z urządzeń **Sonel PE/PE6**.  
Program przetwarza dane pomiarowe i tworzy gotowe pliki **CSV/XLSX**, które można otworzyć w dowolnym arkuszu kalkulacyjnym.

---

## ⚙️ Funkcje (aktualna wersja)

- Import plików pomiarowych z oprogramowania **Sonel PE/PE6**  
- Automatyczne przetwarzanie danych i tworzenie raportu lokalnie (CSV/XLSX)  
- Intuicyjny interfejs graficzny (GUI) – żadnej pracy w terminalu  
- Wybór katalogu wejściowego i generowanie raportu jednym kliknięciem  
- System licencji DEMO / PRO  
- Bezpieczne działanie w trybie lokalnym (żadne dane nie są wysyłane do Internetu)
